# RepoLens Frontend

Foundation skeleton — React 19 + TypeScript 5 + Vite 7 (see `docs/09`, `docs/14`, `DESIGN.md`).

## Local development

```powershell
npm install
npm run dev      # start dev server (http://localhost:5173)
npm run build    # typecheck + production build
npm test         # run Vitest suite
```
